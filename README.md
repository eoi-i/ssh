# خادم طرفية SSH احترافي بلغة بايثون

خادم طرفية (Terminal Server) يعمل على لينكس، يستقبل اتصالات عبر SSH ويوفر شل تفاعلي حقيقي (PTY) لكل جلسة. مبني على مكتبة `paramiko`. مناسب للاستضافة على **Fly.io** والاتصال من تطبيقات الجوال أو أي عميل SSH.

## الميزات
- 🔐 خادم SSH متكامل (تشفر وتفاوض عبر `paramiko`)
- 🖥️ طرفية تفاعلية حقيقية (PTY) مع دعم أبعاد النافذة وألوان ANSI
- 👤 مصادقة بكلمة مرور (نص عادي أو مجزأة بـ `sha256:`) مع تحديد عدد المحاولات
- 🔑 دعم المصادقة بالمفتاح العام (اختياري)
- ⚙️ قابل للتخصيص عبر `config.json` (المضيف، المنفذ، المستخدمين، الشل، رسالة الترحيب)
- 📋 سجلات احترافية مع تدوير تلقائي
- 🛑 إيقاف أنيق عند استقبال إشارات الإيقاف
- 🐳 جاهز للنشر على **Fly.io** عبر `Dockerfile` و `fly.toml`

## التشغيل محلياً
```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/python ssh_server.py --host 127.0.0.1 --port 2222
```
ثم اتصل من أي عميل SSH:
```bash
ssh -p 2222 admin@127.0.0.1
# كلمة المرور: admin123
```

## النشر على Fly.io
```bash
# 1. ثبّت flyctl من https://fly.io/docs/hands-on/install/
fly auth login
fly apps create python-ssh-terminal   # غيّر الاسم في fly.toml إن لزم
fly deploy
```

بعد النشر، العنوان الافتراضي: `python-ssh-terminal.fly.dev:2222`

## الاتصال من تطبيقات الجوال
| التطبيق | النظام | الإعدادات |
|---------|--------|-----------|
| Termius | iOS / Android | المضيف: `python-ssh-terminal.fly.dev`، المنفذ: `2222` |
| JuiceSSH | Android | نفس الإعدادات أعلاه |
| ConnectBot | Android | نفس الإعدادات أعلاه |
| iTerminal | iOS | نفس الإعدادات أعلاه |
| أي عميل SSH | أي نظام | المضيف + المنفذ + اسم المستخدم + كلمة المرور |

بيانات الدخول الافتراضية:
- اسم المستخدم: `admin`
- كلمة المرور: `admin123` (**غيّرها في `config.json` قبل النشر للإنتاج**)
